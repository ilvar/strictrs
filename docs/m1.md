# M1 lint pass

M1 merges compiler diagnostics, supported Clippy lints, and strictrs-specific source checks into the diagnostic contract introduced by M0.

Clippy-backed rules are translated to stable `strictrs::` codes. Project-specific checks currently cover explicit public return types, mutable globals, catch-all arms in files containing local enums, and filesystem/network/process calls outside modules marked with `// strictrs: capability`.

The custom source checks are intentionally conservative and dependency-light. Future work may replace lexical checks with compiler-integrated analysis without changing the public JSON contract.
