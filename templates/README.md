# __CRATE__

Generated by `strictrs new` with Rust 1.97.1.

## Validate

```bash
cargo fmt --check
cargo clippy --all-targets --all-features --locked -- -D warnings
cargo test --locked
strictrs check .
```

## Property tests

`tests/properties.rs` contains a starter invariant using the exact-pinned `proptest` dev dependency. Replace the sample property with domain invariants; generated inputs are reduced to a minimal failing case when a property breaks.

Run only the property suite with:

```bash
cargo test --locked --test properties
```

## Docker

The `Dockerfile` has two entry paths that share one runtime stage
(`debian:bookworm-slim`, non-root):

```bash
# compile inside the image (local use)
docker build -t __CRATE__:dev .

# copy a binary already built in dist/ (used by CI)
docker build --target from-artifact -t __CRATE__:ci .
```

## Continuous integration

`.github/workflows/ci.yml` runs on pull requests and is reusable
(`workflow_call`). The `rust` job (in `rust:1.97-bookworm`) runs `cargo fmt
--check`, clippy `-D warnings`, `cargo test`, builds the release binary, uploads
it as an artifact, runs `strictrs check`, and shellchecks `scripts/`. The `image`
job builds the runtime image from that artifact and smoke-tests it. Rust compiles
exactly once per run. Image publishing is intentionally left out — add it as a
separate workflow for your registry.

## Pre-commit

`.pre-commit-config.yaml` runs whitespace/merge/private-key/YAML hygiene hooks,
`shellcheck`, `bump-version`, and local `cargo fmt --check`, clippy, `cargo
test`, and `strictrs check`.

```bash
pip install pre-commit && pre-commit install
pre-commit run --all-files
```

## Committing

`scripts/commit.sh` runs the same gate as CI, bumps the patch version when the
image content changed (`scripts/bump_version.py`), then commits.

```bash
./scripts/commit.sh "message"        # stage, check, bump, commit
./scripts/commit.sh -p "message"     # ... and push
./scripts/commit.sh -n "message"     # skip checks (docs-only fix)
```

## Small static release

```bash
cargo release-small
```

The release alias uses the pinned Rust 1.97.1 stable toolchain, the prebuilt `x86_64-unknown-linux-musl` standard library, and the footprint profile in `Cargo.toml`.
