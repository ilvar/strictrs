# M1 lint pass

M1 merges compiler diagnostics, supported Clippy lints, and strictrs-specific source checks into the diagnostic contract introduced by M0.

Clippy-backed rules are translated to stable `strictrs::` codes. Non-panic bans run across all targets, while panic APIs are denied only in production targets so `#[cfg(test)]` code retains its explicit exemption. Project-specific checks cover explicit public return types, mutable globals, catch-all arms involving locally defined enums, and filesystem/network/process calls outside modules marked with `// strictrs: capability`.

The custom source checks are intentionally conservative and dependency-light. Future work may replace lexical checks with compiler-integrated analysis without changing the public JSON contract.
